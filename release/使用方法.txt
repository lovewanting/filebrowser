好思路，双击显示菜单，用 `choice` 命令做交互选择
完成。现在 `manage.bat` 支持**两种模式**

**模式 1：双击运行**（无参数）→ 显示交互菜单

```
 ============================================
     File Browser 管理
 ============================================

     1. 启动服务 (后台运行)
     2. 停止服务
     3. 重启服务
     4. 查看状态
     5. 退出

 ============================================
   请输入选项 (1-5):
```

- 按 `1` → 启动 → 完成后按任意键回到菜单
- 按 `4` → 查看状态 → 完成后回到菜单
- 按 `5` → 退出

**模式 2：命令行带参数**（或从 CMD/PowerShell 调用）

```
manage.bat start
manage.bat status
manage.bat stop
manage.bat restart
manage.bat console
manage.bat help
```
